## ✨ امکانات

- 🏛️ **بخش‌های اصلی:** معلمین، شاگردان، سرمعلمین، کارمندان، اولیا، کتاب‌خانه، اسناد
- ➕ **بخش دلخواه:** امکان ایجاد هر بخش جدید در آینده (با تغییر نام و حذف)
- 📚 **کتاب‌خانه:** ثبت کتاب‌ها با پیوست فایل **متنی (TXT)، PDF و Word**
- 👥 **سیستم کاربران:** ساخت یوزر و رمز برای هر شخص (معلم، شاگرد، کارمند، ولی شاگرد و...)
- 🔐 **دسترسی نقش‌ها:** هر نقش فقط بخش‌های مجاز خود را می‌بیند (قابل تنظیم توسط مدیر)
- 📤 **خروجی در هر بخش:** متنی (TXT)، **ورد (Word)** و **پی‌دی‌اف (PDF)** — مخصوص مدیر
- 🔎 جست‌وجوی سریع در هر بخش
- 📅 تاریخ‌ها به تقویم جلالی (ماه‌های افغانی) با اعداد دری
- 🌐 رابط کامل دری، راست‌به‌چپ (RTL)
- ℹ️ بخش درباره: معرفی اپ و اطلاعات تماس سازنده

## 📱 نصب

1. فایل `NedaAlQalam-School-v1.0.apk` را به گوشی منتقل کنید (اندروید ۷ به بالا).
2. اگر پرسید، اجازه «نصب از منابع ناشناس» را بدهید (هشدار Play Protect طبیعی است).
3. بار اول، **حساب مدیر مکتب** را بسازید (نام، نام کاربری، رمز).
4. از منوی 👥 کاربران، برای هر شخص حساب و نقش بسازید.

## 🔨 بیلد از سورس

پیش‌نیاز: JDK 17+ و Android SDK (platforms;android-34 + build-tools;35.0.1)

```bash
# مسیر SDK و JDK را در ابتدای build_apk.sh تنظیم کنید
bash build_apk.sh
```

بیلد بدون Gradle انجام می‌شود: `aapt2 → javac → d8 → zipalign → apksigner`

## 📂 ساختار پروژه

```
AndroidManifest.xml
build_apk.sh              ← اسکریپت بیلد کامل
src/com/nedaqalam/school/
  App.java                ← Application + کاربر جاری
  Fa.java                 ← ارقام دری + تقویم جلالی
  User.java               ← مدل کاربر
  Sec.java                ← مدل بخش
  Rec.java                ← مدل رکورد (شامل پیوست)
  Store.java              ← ذخیره‌سازی JSON + نقش‌ها/دسترسی‌ها
  ExportUtil.java         ← ساخت خروجی TXT و HTML(Word/PDF)
  SplashActivity.java     ← صفحه خوش‌آمد
  LoginActivity.java      ← ورود + ساخت حساب مدیر بار اول
  MainActivity.java       ← فهرست بخش‌ها
  RecordsActivity.java    ← رکوردهای بخش + جست‌وجو + خروجی‌ها
  RecordEditorActivity.java ← ثبت/ویرایش + پیوست فایل
  UsersActivity.java      ← مدیریت کاربران و دسترسی نقش‌ها
  AboutActivity.java      ← درباره اپ و اطلاعات سازنده
res/                      ← لایوت‌ها، رشته‌های دری، آیکون‌ها
```
